# 개발 계획서 — 사진 기준 Editable → Moldable 데모 (figure.rebuilder.ai/3dgen)

기준일 2026-09-28. 사용자 지시 4단계를 그대로 작업 단위로 옮기고, 각 단계의 **구현 위치·완료 게이트·현재 상태**를 적었다. 상태 표기는 `완료(코드+테스트)`, `부분`, `차단(BLOCKED)`.

## 사용자 지시 (원문 요약)

1. S3의 정답 CAD 50개의 **암수와 작업 구조**를 분석한다. DPAI 확장판 교육 PDF로 **Editable 3D·Moldable 3D의 구조와 검증 기준**을 정리하고 **검증 루프**를 만든다.
2. AI 3D 입력은 **참고용**, Blender로 **다시 만든다**. 입력은 **원본 사진 + 3D 모델**. **사진에서 만든 다시점 이미지가 정답**이다. 3D 입력에서는 **파트가 어떻게 나뉘는지만** 참고한다. Astra로 파트가 깔끔하게 나뉘지 않았거나 같은 면(같은 망토·같은 눈)이 지저분하게 나뉜 곳을 판단하는 **모델**을 만들고, 판단 결과로 **Blender에 파트 분리 명령**을 내린다.
3. 파트 간 암수 구조를 Astra로 **이미지 생성**한다.
4. 그 이미지를 따라 **몰더블 3D**를 만든다. **에디터블을 먼저**, 몰더블은 **에디터블 기준으로 암수를 넣고 합칠 파트를 합치고 몰더블 조건(PDF)으로 체크·수정**한다. **에디터블도 모든 면이 닫혀야** 한다.

## 단계별 계획과 상태

### 1. 정답 CAD 50개 + PDF 기준 + 검증 루프

| 작업 | 구현 | 상태 |
|---|---|---|
| 50개 표본 목록·해시 | `reference/s3_50_manifest.csv` (50개, 서로 다른 SampleId, SHA-256) | 완료 |
| 무결성 검증 | `scripts/s3_reference.py verify --dir …` (크기+SHA-256, 50/50 요구) | 완료(도구). 실행은 사용자 PC에서 |
| S3 다운로드 | `scripts/s3_reference.py download` (boto3, 사용자 AWS 프로필) | 도구 완료. **이 클라우드 세션은 AWS 자격증명이 거부**되어 직접 실행 불가 |
| .cly 메타 | `app/reference/cly.py` 메타 문자열만. 형상·암수 추론 금지 | 완료 |
| 암수 자동 계측 | `app/reference/analyze.py`: 포위도 광선(수/암), 볼록도(소켓 벽 오검출 제거), 철수축, 단면 원형도(원형/키/넥플러그), 간극, 소켓 벽 두께 | 완료 — 합성 정답(간극 0.15, 벽 1.2)을 정확히 계측하는 테스트 통과 |
| 50개 실제 분석 | FreeForm에서 표본별 파트 STL export → `analyze` → `library` | **차단**: FreeForm 실행환경 + 파일 필요. 분석 0/50 |
| PDF 기준 정리 | `docs/PDF_CRITERIA_KO.md`, `contracts/criteria.json` (게이트·페이지·맥락 수치) | 완료 |
| 검증 루프 | Editable: 사진 실루엣→카빙→재구성→무결성 재검사→채택/되돌림. Moldable: 조인트 오프셋·반경 재시도→전 조인트 재검증→간섭→삽입→PDF 검사. Split: 사람 승인이 라벨로 쌓여 판정 모델 재적합 | 완료 |

**게이트 1**: 50/50 무결성 + 실제 형상에서 관찰한 모델·접점 수 보고 + `joint_library.json` `READY`(10개 이상 표본). 현재 라이브러리 `EMPTY` → Moldable의 `s3_grounded_joint_parameters = NOT_VERIFIED`, 치수는 `criteria.json`의 **표시된 가정값** 사용.

### 2. 입력 프로토콜, 사진 정답, 분할 판정 모델 → Blender 분리 명령

| 작업 | 구현 | 상태 |
|---|---|---|
| 사진+GLB 별도 필드, 열린 GLB 허용 | `POST /3dgen/api/jobs` (photo 필수, glb 필수), `intake.py` | 완료 |
| 사진 → 다시점 | `views.generate`(Astra 이미지) / 업로드 / "원본 사진을 정면으로" | 코드 완료, Astra 실호출은 키 필요 |
| 사람 승인·실루엣 | `views.approve` (정면 필수) → 마스크 | 완료 |
| 분할 근거 | `segmentation.analyze`: 경계 길이, 공유율, 꺾임각(연속면), 지그재그(스케일 인식), 파편도 | 완료 |
| 판정 모델 | `SplitJudge` 로지스틱 모델(사전 가중치 + 승인 라벨로 MAP 재학습), 결정 merge/resplit_clean/keep | 완료 |
| Astra 확인 | 승인 다시점 + 파트 렌더 + 근거 → 경계별 판정 JSON; 불일치/불확실은 사람 검토 | 코드 완료, 실호출은 키 필요 |
| Blender 명령 | `join`(병합), `clean_resplit` 라벨 → `separate`/`replace`(깨끗한 재분할) | 완료(실 Blender 실행 테스트) |

**게이트 2**: 사진·GLB 역할이 API/UI/보고서에서 분리. 병합·재분할 결정 전부 사람 승인. 합성 평가: 망토 3조각·눈 2조각·머리 2조각 → 병합 4건 정확, 지그재그 3.8~5.5 → 재분할 후 1.24.

### 3. Editable (모든 파트 닫힘)

| 작업 | 구현 | 상태 |
|---|---|---|
| Blender 재구성 | 파트별 프로세스: 반 복셀 용접 → 구멍 채움(작은 틈) 또는 설계 두께 2.0mm 쉘(시트형) → 복셀 → 스무딩 → 재복셀(자기교차 제거) → QuadriFlow(시드 3회, 닫힘·단일 셸·편차·자기교차 모두 통과해야 채택) | 완료 |
| 사진 기준 보정 | 승인 뷰 실루엣 IoU → 초과분 비주얼 헐 교집합 → 재구성 → 무결성 실패 시 직전본 유지 (최대 2회) | 완료 (합성: IoU 0.93 → 0.97) |
| 부족분 | 사진에는 있고 모델에 없는 부분은 **보고만**(파랑 diff), 임의 생성 금지 | 완료 |
| 게이트 | 전 파트 폐합, 단일 셸, 분할 승인, 사진 실루엣 ≥ 0.85, 자기교차 스크린, 쿼드 ≥ 90%, OBJ 왕복, 스케일/축 | 완료 |
| ZBrush 조형 왕복 | 사람 증거 | `NOT_VERIFIED` (보고용) |

### 4. 암수 개념도(Astra) → Moldable (Editable 파생)

| 작업 | 구현 | 상태 |
|---|---|---|
| 병합 제안 | 원본 솔리드 기준, 작은 내장 디테일(눈 등, PAD 도색 대상 p.31-32) → 병합 | 완료 |
| 생산 분할 | 원본 병합 → 겹침 해소(작은 파트 유지, 큰 파트를 0.1mm 간극으로 카빙) | 완료 |
| 접점 그래프 | 같은 파트 쌍의 떨어진 접점도 별도 ID | 완료 |
| 암수 계획 | 접점당 1개: 큰 부피 = 암, 공통 삽입축, 원형/D-키/넥플러그, 크기 등급, 라이브러리 검색 | 완료 |
| Astra 개념도 | 접점별 이미지 + JSON 사양(라이브러리 선택지 안에서만 채택, 신뢰도 < 0.6이면 사람 검토) | 코드 완료, 실호출은 키 필요 (`joint_concept_sheets = BLOCKED`) |
| 암수 기하 | 수 핀 합집합, 간극 소켓 차집합, 보스는 소켓 봉투의 10% 이하만(외형 보호), 핀 노출 금지 | 완료 |
| 검증 | 간섭 0, 서브어셈블리 삽입 스윕, 두께 p05, 샤프포인트(얇은 군집), 언더컷(최적 당김방향), ABS 5mm, 자립, 표기면, 소형부품, OBJ 왕복 | 완료 (합성: 차단 게이트 전부 PASS) |
| 공정·실물 승인 | 사람 | `NOT_VERIFIED` |

## 중단 조건

키 없는 Astra, 읽을 수 없는 CLY, 사진 없는 외형, 승인 안 된 소재·공차, 도메인 소유권 불명 → 임의 추정하지 말고 `BLOCKED`와 필요한 결정을 남긴다.
